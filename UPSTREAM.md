## Changes in this fork

The application source is retained from the upstream version. This fork adds an English and Chinese project overview, design case study, contribution and source notes, presentation artwork, a local setup guide, and a blank `.env.example`. The `.gitignore` retains upstream rules and adds broader local-environment exclusions. The original README is preserved in [docs/UPSTREAM_README.md](docs/UPSTREAM_README.md).

The team is Emma Coye, Nithya Sunkara Indlamuri, Luna Jiang, and Chloe Jian. Chloe's confirmed contribution is interface design, Figma prototyping, and visual design. Copying the source does not change attribution for development or other team work.
